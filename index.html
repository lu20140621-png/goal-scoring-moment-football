界面说明

这一版改成真正由系统判定攻防：
1. 已删除“红队 +1 / 蓝队 +1”手动按钮。RUN / PASS 最终成功后，系统自动增加进度；失败则不加。
2. 进攻方打出 RUN 后：自动切到对方防守，对方可使用 TACKLE / BLITZ / 不防守。
3. 进攻方打出 PASS 后：先选择队友；若当前持球者是技能可用的 QB，会先弹出“是否使用身份卡技能”；确认后才切到对方防守。
4. PASS 防守：对方可 INTERCEPTION / BLITZ / 不防守。INTERCEPTION 成功后防守球员直接获得球权。
5. TACKLE / INTERCEPTION 出现后，系统切回进攻方，可以使用 BLOCK；BLOCK 后再切回防守方，可用 BLITZ 最终反制。
6. 多人本地模式下，每次红蓝双方切换都会先出现“轮到蓝队 / 轮到红队”的遮挡页，像大富翁一样交接设备。
7. QB 点击“使用技能”后技能立即消耗。若 PASS 最终成功，本次系统自动多加 1 格；若 PASS 失败，技能也不会返还。
8. 每队都从 50 码线开始，50 只是起始位置，不算一次成功。第1次成功到40，第2次到30，第3次到20，第4次到10。
9. 第4次成功到达10码线后，不需要第5次进攻；当前持球者立即自动冲进对方 END ZONE，并弹出 TOUCHDOWN / 达阵成功。之后该队推进位置重置到50。
10. 获得 1 个🏈后进入下一回合；先获得 3 个🏈的队伍获胜。
