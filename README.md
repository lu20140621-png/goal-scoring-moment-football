# Goal-Scoring Moment — American Football

Standalone web version of the Goal-Scoring Moment American football game.

- 2v2 / 3v3 / 4v4
- Solo demo / local multiplayer
- Chinese / English switch
- RUN / PASS / TACKLE / INTERCEPTION / BLOCK / BLITZ
- 50-yard drive progression
- 4 successful plays = TOUCHDOWN
- First team to 3 footballs wins

Main page: `index.html`
